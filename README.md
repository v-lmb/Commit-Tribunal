Why is it important to write commit messages correctly?

Here is a list of reasons that answer the question

- to quickly develop good writing habits.
- to know exactly what has been changed in the code if we ever need to go back to it without getting confused.
- in the case of a group project, everyone needs to be able to know what has been changed so as not to waste time searching.
- Hugo is inventive when it comes to penalties and he reads everything.
- On personal projects, after a break of varying length, it is highly likely that we will no longer remember where we were. Reviewing your code and the changes made, written correctly, can help you remember the thought process you were following.
- Recruiters also see our beautiful commit messages.
- Commit messages are not rage rooms, therapy sessions, or tweets.
